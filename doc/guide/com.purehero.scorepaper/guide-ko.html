처음 시작하기

ScorePaper는 인쇄 악보의 사진에서 음표와 리듬을 인식하고, 결과를 직접 수정하는 앱입니다. 인식은 기기 안에서 실행되므로 인터넷 연결 없이 사용할 수 있습니다.

  1. 홈에서 악보 촬영하기를 누릅니다. 이미 사진이 있다면 사진에서 가져오기를 선택합니다.
  2. 사진의 네 모서리를 악보에 맞추고 보정을 적용합니다.
  3. 악보 인식을 눌러 편집 가능한 악보를 불러옵니다.
  4. 원본과 비교하며 음표와 리듬을 확인하고 필요한 부분을 고칩니다.
  5. 내보내기에서 PDF 또는 PNG로 저장합니다.
현재 작업은 초안으로 기기에 자동 저장됩니다. 새 악보를 시작하면 현재 초안이 대체됩니다. 보관할 작업은 먼저 PDF나 PNG로 내보내세요. 내보낸 파일은 편집용 프로젝트 백업과는 다릅니다.

카메라로 찍어 악보 불러오기

읽기 쉬운 사진을 준비하세요

  • 악보를 가능한 한 평평하게 펴고, 밝은 곳에서 촬영하세요.
  • 카메라를 종이와 평행하게 두고 흔들리지 않게 찍으세요.
  • 손가락·그림자·빛 반사가 음표를 가리지 않게 하세요.
  • 인식할 보표와 음표가 잘리지 않게 담으세요. 음표가 너무 작으면 가까이 찍거나 범위를 나눠 보세요.

악보 촬영하기를 누르면 기기의 카메라 앱이 열립니다. 사진을 찍고 카메라 앱에서 사용을 확인하면 ScorePaper로 돌아옵니다. 카메라 앱을 사용할 수 없다면 사진에서 가져오기로 이미지 파일을 선택하세요.

모서리를 맞추고 인식하세요

사진의 네 모서리를 악보 영역에 맞춥니다. 점을 움직이기 어렵다면 화면의 모서리 선택 및 화살표 버튼을 사용하세요. 네 모서리가 서로 교차하지 않게 맞춘 뒤 보정을 적용합니다.

사진 확인 화면에서 악보 인식을 누르고 처리가 끝날 때까지 기다리세요. 잘못 잡힌 범위는 모서리 조정으로 돌아가 수정할 수 있습니다.

인식 결과는 촬영 상태와 악보의 글꼴·복잡도에 따라 달라집니다. 음표·가사·표현 기호가 잘못 읽힐 수 있으므로 연주나 출력 전에 원본과 대조하세요.

원본과 인식 결과 비교하기

편집 화면의 원본 대조에서 사진과 편집 악보를 비교하세요. 세로 화면에서는 위아래로, 가로 화면에서는 좌우로 확인할 수 있습니다. 원본 사진은 두 손가락으로 확대·축소하고 드래그로 이동합니다.

  • 확인 완료: 사용자가 검토한 부분으로 표시합니다.
  • 나중에: 다시 확인할 부분으로 남깁니다.
  • 대조 닫기: 일반 편집 화면으로 돌아옵니다.

이 표시는 사용자의 검토 상태이며 인식 정확도 점수가 아닙니다. 필요하면 더보기 메뉴에서 사진을 다시 인식할 수 있지만, 재인식하면 현재 편집 내용이 새 인식 결과로 대체됩니다.

음표 선택과 기본 편집

마디를 누르면 크게 볼 수 있습니다. 수정할 음표를 누르세요. 현재 마디는 파란색으로, 선택한 음표는 주황색 테두리로 표시됩니다. 다른 보표의 음표도 직접 눌러 선택할 수 있습니다. 선택 정보에서 마디·보표·성부를 확인하세요.

음표 이동 OFF가 기본 모드입니다.

  • 길게 / 짧게: 음표 길이를 늘리거나 줄입니다.
  • 가운데 길이 버튼: 온음부터 64분음표까지 직접 선택합니다.
  • 이전 음 / 다음 음: 같은 보표·성부의 음표를 선택합니다.
  • 이전 마디 / 다음 마디: 인접 마디로 이동합니다.

＋ 추가에서 음표나 쉼표를 추가하고, 기호 목록에서 수정할 기호를 선택할 수 있습니다. 실수했다면 실행 취소, 되돌린 편집을 다시 적용하려면 다시 실행을 누르세요. 전체 악보로 페이지 보기로 돌아갑니다.

음높이와 박 위치 옮기기

음표 이동을 켜면 화살표의 역할이 바뀝니다.

  • 높게 / 낮게: 같은 보표에서 한 음계씩 음높이를 바꿉니다. 반음 변경에는 ♯·♭·♮ 도구를 사용하세요.
  • 왼쪽 / 오른쪽: 선택한 음표 자체를 앞이나 뒤의 박으로 옮깁니다. 이동 간격은 8분 또는 16분음표 길이로 선택합니다.

음표의 길이는 유지됩니다. 떠난 자리는 쉼표로 채우고, 도착 지점에는 충분한 쉼표가 있어야 합니다. 다른 음표를 밀거나 서로 자리를 바꾸지는 않습니다.

마디 경계를 넘거나 다른 음표와 겹치는 이동은 할 수 없습니다. 연음표·꾸밈음·연결선·묶음 경계가 있는 복잡한 경우에도 제한이 있습니다. 쉼표는 이동 모드에서 음높이나 박 위치를 바꿀 수 없습니다. 화면에 표시되는 이유를 확인하세요.

화음·묶음·가사 다듬기

삭제와 화음

음표를 삭제하면 같은 길이의 쉼표가 됩니다. 화음에서는 선택한 음만 지우거나 화음 전체를 쉼표로 바꿀 수 있습니다. 개별 음 선택인지 화음 전체 선택인지 확인하세요. 길이 변경은 화음 전체에 적용됩니다. 쉼표를 삭제하면 해당 길이도 제거되어 뒤의 음표가 앞으로 당겨집니다.

음표 묶기

첫 음표 선택 → 음표 묶기 → 마지막 음표 선택 → 묶기 적용 순서로 진행합니다. 같은 마디·보표·성부의 연속된 8분음표 또는 더 짧은 음표를 묶을 수 있습니다. 묶인 음표를 선택하면 묶음 해제가 표시됩니다. 쉼표나 긴 음표, 연음표 경계를 가로지르는 묶음에는 제한이 있습니다.

가사와 연결선

음표를 선택한 뒤 가사 연속 입력에서 가사를 입력하고 저장·다음으로 이어가세요. 가사 글씨 크기는 5단계로 선택하며 내보내기에도 적용됩니다. 연결선은 시작 음표와 끝 음표를 선택해 적용합니다.

악보 보기와 새 악보 만들기

  • 악보만 보기: 편집 도구를 숨깁니다. 편집으로를 누르면 돌아옵니다.
  • 두 손가락으로 확대·축소하고, 마디를 눌러 크게 볼 수 있습니다.
  • 페이지는 더보기(⋮) → 페이지 선택으로 이동합니다. 악보만 보기에서는 페이지 화살표를 사용할 수 있습니다.
  • 기기를 가로로 돌리면 악보가 한 줄로 이어집니다. 좌우로 밀어 읽으세요. 세로로 돌리면 페이지 보기로 돌아옵니다.
  • 사진 없이 만들려면 홈에서 빈 오선지로 시작을 선택합니다. 현재 작업을 보관하려면 먼저 내보내세요.

PDF·PNG로 저장하기

  1. 상단 내보내기를 누릅니다.
  2. 필요하면 제목 포함을 선택합니다. 제목은 편집 화면 상단에서 바꿀 수 있습니다.
  3. PDF는 전체 페이지, PNG는 현재 페이지를 저장합니다.
  4. 기기의 파일 저장 화면에서 위치와 파일 이름을 확인하고 저장을 완료합니다.

제목은 PDF 첫 페이지 또는 PNG 상단에 들어갑니다. 가사 크기 설정도 반영됩니다. 선택한 음표의 강조 표시는 저장되지 않습니다.

저장되는 것은 편집한 악보입니다. 원본 사진을 그대로 PDF로 묶는 기능이 아닙니다. 내보낸 파일은 파일 앱에서 확인하고 필요할 때 공유하세요.

문제가 있을 때

음표가 인식되지 않거나 잘못 읽혀요.

더 밝고 선명한 사진으로 시도하고 보표가 잘리지 않았는지 확인하세요. 넓거나 복잡한 악보는 범위를 나눠 촬영해 보세요. 인식된 결과는 원본과 대조해 직접 수정할 수 있습니다.

음표가 원하는 곳으로 이동하지 않아요.

음표 이동 모드가 켜져 있는지, 같은 마디 안에 충분한 빈 박이 있는지 확인하세요. 다른 음표와 겹치거나 복잡한 기호 연결이 있으면 이동이 제한됩니다.

저장 또는 내보내기가 안 돼요.

악보 로딩과 편집 저장이 끝났는지 확인하세요. 파일 저장 화면에서 쓰기 가능한 다른 폴더를 선택하고 기기의 남은 공간도 확인하세요.

이전 작업을 다시 열고 싶어요.

홈의 이어서 편집으로 현재 초안을 엽니다. 여러 악보를 보관하는 보관함은 아니므로 새 악보를 시작하기 전에 필요한 결과를 내보내세요. 앱 삭제·데이터 삭제 시 기기 내 초안을 잃을 수 있습니다.

인터넷이 필요한가요?

악보·문자 인식 모델은 앱에 포함되어 오프라인으로 동작합니다. 온라인 가이드 열기, 메일 전송, Google Play 업데이트에는 연결이 필요할 수 있습니다.

언어·업데이트·문의

화면은 기기 또는 앱 언어 설정에 따라 한국어·영어로 표시합니다. 그 밖의 언어에서는 영어를 사용합니다. 직접 입력한 제목과 가사는 번역하지 않습니다.

Google Play의 중요한 업데이트가 확인되면 안내가 표시됩니다. 필수 업데이트를 취소한 경우 다시 시도하거나 앱을 종료해야 합니다. 자동 확인은 홈에서 저장이 끝난 뒤 진행되며, 오프라인 또는 Google Play 외부 설치에서는 제한될 수 있습니다.

홈 또는 악보 메뉴의 오류 제보에서 문제를 작성하고 내용을 확인한 뒤 메일 앱으로 보내세요. 앱 버전·기기 모델·Android 버전이 포함되며 사진과 악보는 자동 첨부하지 않습니다.
